Modify the route

Select a checkpoint, then add a new node after it or remove the selected node. The Python backend updates both links.

Why a doubly linked list?

Survey checkpoints can change during field work. A node keeps a reference to the previous and next checkpoint, making forward/backward traversal and local insertion or deletion natural operations.
